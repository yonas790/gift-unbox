# GiftBox Unboxing Animation

A visually appealing, interactive gift box animation built with **React** and **Vite**, featuring snow effects, keyboard accessibility, and sound effects.

---

## Features

- 3D rotating gift box animation
- Open/close on **click**, **Enter**, or **Space**
- Snowflake background effect using `<canvas>`
- Shows pressed key pop-up for 1 second when keyboard used
- Plays opening sound effect when box opens
- Smooth CSS animations

---

## Setup Instructions

1. **Clone the repository:**

```bash
git clone git@github.com:yonas790/gift-unbox.git
cd gift-unbox
```

2. **Install dependencies:**

```bash
npm install
```

3. **Run the development server:**

```bash
npm run dev
```

4. **Open in browser:**

```
http://localhost:5173
```

5. **Build for production:**

```bash
npm run build
```
